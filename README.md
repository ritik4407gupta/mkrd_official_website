# MKRD Engineers — Cinematic Web Experience

A premium, cinematic website experience developed for **MKRD Engineers
Pvt. Ltd.**

The project transforms the client's existing engineering-focused website
into an immersive digital experience while preserving its real business
identity and content.

## ✦ Experience

The website combines:

- Cinematic introductory animation
- Interactive door-opening transition
- Editorial homepage design
- Scroll-controlled cinematic video
- Video expansion and parallax
- Smooth scrolling with Lenis
- GSAP + ScrollTrigger choreography
- Horizontal service exploration
- Interactive service cards
- Selective Three.js / React Three Fiber experiences
- Robotic-hand interactions for deeper service transitions
- Project and gallery storytelling
- Responsive and accessible layouts
- Large-scale cinematic footer brand reveal

## ✦ Technology

- Next.js
- React
- TypeScript
- Three.js
- React Three Fiber

- Lenis

- Swiper

## ✦ Design Direction

The visual direction focuses on a restrained engineering aesthetic:

**Graphite · Soft Steel · Smoky Navy · Off-White · Muted Teal**

The goal is to create a sophisticated industrial atmosphere without
falling into the typical neon, cyberpunk, or AI-generated visual style.

The experience prioritizes:

**Meaning → Composition → Motion → Lighting → Material → Effects**

## ✦ Client

**MKRD Engineers Pvt. Ltd.**

The project is designed around MKRD's engineering and manufacturing
capabilities, including mould/tool design, reverse engineering,
3D printing, mould-flow analysis, animation and related engineering
services.

## ✦ Inspiration

The opening experience takes limited inspiration from the immersive
entry quality of ITom. The reference is used only for the introductory
sequence up to the door-opening moment.

The rest of the website is an original MKRD-specific visual system.
